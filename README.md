# Brick Buddies 🧱

A simple, joyful Lego-style toy-world game for the browser. Keyboard or gamepad. No losing, lots of things to collect, smash, build and press.

**Play:** https://8gsean.github.io/brick-buddies/

| Action | Keyboard | Gamepad |
|---|---|---|
| Move | WASD / arrows | Left stick |
| Jump / double jump / glide | Space | A |
| Smash | X, J, Enter, click | X / B |
| Honk & dance | F | Y |
| Camera | Q / E, drag | Right stick / bumpers |

Built with [Three.js](https://threejs.org) (r149, bundled in `lib/`).
